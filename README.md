## ErlendCopy2000 v1.3

The unnecessarily advanced dual-drive optical media archival system.

### Features

- Two optical drives operating simultaneously
- Automatic disc detection and ejection
- Configurable file exclusions
- SHA-256 checksums
- Local, USB and network save locations
- Blank-disc detection
- Detailed technical manifests

### Requirements

- Windows 10 or Windows 11
- 64-bit Windows
- At least one optical drive

Python is not required.

> This application is not digitally signed. Windows SmartScreen may
> display an unknown publisher warning.
